# Script para Máquina Virtual ASIX

Este repositorio contiene recursos y guías para prácticas de administración de sistemas en el ciclo ASIX (Administració de Sistemes Informàtics en Xarxa).

## Contenido

### 1. Script de Creación de Usuarios en Active Directory (`script`)
Script de Windows para crear usuarios en Active Directory a partir de datos CSV.

### 2. Práctica de Nextcloud en Ubuntu Server (`Practica_Nextcloud_Ubuntu_Server.pdf`)
Guía completa paso a paso para instalar y configurar un servidor cloud personal con Nextcloud sobre Ubuntu Server 22.04 en VirtualBox.

**Contenido de la práctica:**
- Creación de máquina virtual en VirtualBox
- Instalación de Ubuntu Server 22.04 LTS
- Configuración de LAMP stack (Linux, Apache, MySQL/MariaDB, PHP)
- Instalación y configuración de Nextcloud
- Implementación de SSL/HTTPS
- Pruebas y verificación del servidor
- Preguntas de reflexión para los alumnos

**Uso:**
1. Descarga el archivo PDF: `Practica_Nextcloud_Ubuntu_Server.pdf`
2. Sigue los pasos detallados en el documento
3. Documenta cada paso con capturas de pantalla según las indicaciones
4. Completa las preguntas de reflexión al final
5. Entrega el PDF con todas las capturas y reflexiones

## Requisitos para la práctica de Nextcloud

- VirtualBox 6.0 o superior
- Ubuntu Server 22.04 LTS ISO
- Mínimo 4 GB RAM disponibles
- Mínimo 20 GB espacio en disco
- Conexión a Internet
